## 📖 这是什么

## ❓ 常见问题

<details>
<summary><b>会被封号吗？</b></summary>

本软件**只读取官方客户端接口，不侵入游戏、不修改对局数据**。但任何第三方工具都存在风险，**请自行评估后再决定是否使用**。
</details>

<details>
<summary><b>支持哪些区服？</b></summary>

**只做国服（腾讯服）**。外服不在支持范围内。
</details>

<details>
<summary><b>需要管理员权限吗？</b></summary>

**不需要**。安装与运行都不要求管理员权限。
</details>

<details>
<summary><b>怎么彻底退出？</b></summary>

点窗口右上角的 × **只是隐藏到托盘**。要真正退出，请**右键点击托盘图标 → 退出**。
</details>

<details>
<summary><b>会上传我的数据吗？</b></summary>

**不会**。所有数据都存在你自己电脑上，软件不做任何用户数据收集。
</details>
